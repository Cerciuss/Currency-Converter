# Currency-Converter
💱 C++ Currency Converter
A simple, interactive, and object-oriented command-line application built in C++ to easily convert currencies.

✨ Features
Object-Oriented Design: Built using C++ classes and encapsulation for clean, maintainable code.

Interactive Menu: An easy-to-use console interface that prompts the user for quick currency selections.

Multiple Currencies: Instantly convert USD to Euro (EUR), Dinari, and Tunisian Dinar (TND) (and vice versa).

Easily Expandable: The simple class architecture makes it very easy to add new currencies or update exchange rates in the future.
